# User Flows

## Initial release flows

1. Register or sign in.
2. Complete pharmacy setup.
3. Import or add stock.
4. Receive stock.
5. Record movements.
6. Monitor expiry.
7. Monitor low stock.
8. Count stock and reconcile.
9. Review reports and exports.

## Deferred flows

- Multi-branch.
- Automated purchasing.
- AI forecasting.
- Offline sync.
